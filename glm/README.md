# BiPro GLM 诗歌生成核心模块说明

本目录下的代码主要实现了基于 GLM-10B-Chinese 模型的中国古典诗词（特别是五言/七言绝句和律诗，即唐诗）的生成。其核心能力依赖于**受限束搜索（Constrained Beam Search）**与**严格的物理格律过滤**两大模块。

## 1. 束搜索 (Beam Search) 实现

为了在生成的每一步能够探索多条可能路径，并在生成过程中排除不合规的诗句，项目实现了一套定制化的束搜索机制。

- **核心代码文件**：`beam_search_strategy.py`
- **核心类/逻辑**：`BeamSearchStrategy`
- **工作机制**：
  在文本自回归生成（主要通过 `bipro_poem.py` 或 `single_gen.py` 中的 `generate_sentence_with_constraint` 函数调用）时，`BeamSearchStrategy` 会在每一步维持多个候选分支（Beams）。
  它与传统的 Beam Search 最大的不同在于：它**深度集成了格律校验器**。在生成下一个词或完整句子时，如果校验器判定当前候选集违背了格律规则，则会返回一个极大的负面惩罚分（例如 `-1000`）。束搜索根据这个惩罚分重新排序，从而将违规的候选分支剪枝（Drop）掉，确保留下的生成结果都是形式上合规的。

## 2. 唐诗物理规则过滤 (Poem Verifier)

为了保证生成的诗歌在形式、平仄、押韵上符合古典近体诗的规范，本系统内置了强无情规则过滤机制。

- **核心代码文件**：`poem_verifier.py`
- **核心函数**：`poem_verifier()` 等相关校验逻辑
- **依赖词典**：`pingshui.txt`（包含《平水韵》韵部和字音平仄标注）
- **具体实现的物理过滤规则**：
  1. **字数与句式限制**：强制校验句子为 5 个字或 7 个字（不含标点符号）。
  2. **防重复与现代字过滤**：
     - 禁止生成结果中包含特定现代白话虚词（如“的”、“些”、“么”、“了”）。
     - 防止句内和相邻句间的重复字现象（“重字”审查）。
  3. **平仄卡位校验**：
     - 遵循近体诗“二四六分明”的铁律，对句子中第 2、4、6 字符的平仄进行严格对照。若不符合当前诗局的韵律阵形，直接返回 `-1000` 惩罚分。
  4. **诗词大忌排查**：
     - **孤平**：校验特定句式中是否出现了犯孤平（即该平而仄，导致全句仅存一个平声字）的情况。
     - **句尾三连同**：严格防止句末出现“三连平”或“三连仄”。
  5. **押韵一致性**：要求押韵句末的字必须处于相同的《平水韵》韵部（一韵到底）。
  6. **关于多音字的妥协处理**：
     系统通过读取词典返回该字符可能的声调数组（`pz`）。如果 `len(pz) > 1`（存在多音字可能），过滤器由于无法结合当前语境消歧，会直接将其“放行”。这意味着系统能保证 100% 符合“词典级规则”，但无法消除因个别多音字带来的语意级出律。
